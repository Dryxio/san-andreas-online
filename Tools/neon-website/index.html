Before you ask

FAQ

Is it free?

Yes. San Andreas Online is free and open source under the GPL-3.0 licence, like Multi Theft Auto itself.

Do I need GTA: San Andreas?

Yes. San Andreas Online doesn't include the game. You need your own copy of the original PC version. The Definitive Edition won't work.

Will it replace my MTA:SA?

No. San Andreas Online installs into its own folder, separate from MTA:SA, so both can live side by side.

Is this the official MTA?

No. San Andreas Online is an independent project based on the open-source code of Multi Theft Auto: San Andreas. It is not run by, affiliated with or endorsed by the MTA team.

Why is the download on GitHub?

GitHub is where the code lives and where each release is built and published. The download button gives you the installer directly; you never have to browse the code.

Can I host my own server?

Yes. Every release ships server packages for Windows x64, Linux x64 and Linux ARM64.

Where can I get help?

Join the San Andreas Online Discord. Players, server owners and developers hang out there.
